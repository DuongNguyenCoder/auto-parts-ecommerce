# UI System

Design style:

- Clean modern ecommerce UI
- Minimal and professional
- Automotive industry feeling

Use:

- TailwindCSS
- Shadcn UI

Border radius:

- rounded-xl default

Spacing:

- Use 4px spacing scale

Typography:

- Clear hierarchy
- Avoid oversized headings

Color palette:

- Primary: zinc/neutral
- Accent: orange/red automotive tone
- Avoid random colors

Shadow:

- Soft subtle shadows only

Buttons:

- Consistent height
- No inconsistent padding
